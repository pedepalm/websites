ACME Internal IT Service Desk Topics

Overview:   ACME Corporation has a service desk where agents take calls for typical IT related issues.   The following is a list of Those issues and their descriptions.

  • PC Hardware
    • Use this for anything hardware relating to PCs
    • Topic Matchings
      • PC, or personal computer, Power supply, Mouse, Screen, Keyboard, PC or Mac battery, hard drive, memory, Monitor, Docking station, Laptop charger, Laptop will not power on, USB port, USB-C port, HDMI port, Ethernet port, Webcam, Microphone, Speakers, Trackpad, Touchscreen, Cracked screen, SSD, External hard drive, Graphics card, Overheating, Fan noise, Laptop hinge
    • Guidance
      • Troubleshooting Guidance – no troubleshooting guidance
  • Windows
    • Topic Matchings
      • Windows 11, Windows operating system, Blue screen, Windows error message, Windows 10, Windows update, Windows update failed, Start menu, Taskbar, File Explorer, Desktop icons missing, Slow Windows, Windows will not boot, Stuck on Windows logo, Safe mode, Startup repair, BitLocker, BitLocker recovery key, Windows activation, Temporary profile, Windows Search, Microsoft Store, Windows Hello, Lock screen, Will not wake from sleep, Windows will not shut down, Display settings, Device Manager
    • Troubleshooting Guidance
      • Windows 11: Open Settings, System, About, and confirm you are on Windows 11. If you are moving from Windows 10, check that your PC is on the ACME upgrade list first. Save your files before you start an upgrade.
      • Windows operating system: Use these steps when Windows is the problem and none of the other Windows items fit. Note your Windows edition, what is going wrong, and when it started. If it still happens after a restart, contact Desktop Support.
      • Blue screen: Write down the stop code on the blue screen, then restart once. If the blue screen comes back, contact Desktop Support and give them that code plus any driver or update you just installed. Do not reinstall Windows yourself.
      • Windows error message: Read the full message and write down the error code. If it is about a printer, a password, email, or one app, follow that topic instead. If a restart does not clear the message, contact Desktop Support with the code.
      • Windows 10: Open Settings, System, About, and check your version. If your PC is eligible, upgrade to Windows 11. If Windows says this version is out of support, contact Desktop Support.
      • Windows update: ACME installs updates on a schedule, usually outside business hours. Open Settings, Windows Update, to see where yours stands. Do not pause updates for more than 7 days.
      • Windows update failed: Open Settings, Windows Update, Update history, and write down the error code. Restart and try the update once more. If it fails again, contact Desktop Support with that code. Do not delete system folders.
      • Start menu: Press Ctrl+Shift+Esc, find Windows Explorer in Task Manager, and choose Restart. If Start still does not open, sign out and sign back in. If a full restart does not fix it, contact Desktop Support.
      • Taskbar: If the taskbar is hidden, turn off auto-hide in taskbar settings, then restart Windows Explorer from Task Manager. If icons disappeared right after an update, contact Desktop Support and name that update.
      • File Explorer: Close File Explorer and open it again. If it says not responding, restart Windows Explorer from Task Manager. If only one folder fails, note that folder path and contact Desktop Support.
      • Desktop icons missing: Right-click the desktop, open View, and turn on Show desktop icons. If Windows says you are on a temporary profile, follow the Temporary profile steps. Restart once before you try anything else.
      • Slow Windows: Notice whether startup, one app, or the whole PC is slow. Open Task Manager and close any app that is high in CPU or disk. If a restart does not help, contact Desktop Support and tell them the process name.
      • Windows will not boot: Note what you see: the logo, a blue screen, a black screen, or a BitLocker prompt. If you see BitLocker, follow the BitLocker steps. Otherwise hold the power button until the PC turns off, wait 30 seconds, and try once. If it still will not start, contact Desktop Support.
      • Stuck on Windows logo: Hold the power button for 10 seconds, wait 30 seconds, and start the PC once. If the logo spins for more than 15 minutes again, contact Desktop Support. Do not repeat that power cycle more than twice.
      • Safe mode: Use Safe mode only when Windows will not start normally. Follow the ACME boot-menu steps for your PC. If you cannot open that menu, contact Desktop Support.
      • Startup repair: If Windows offers Startup Repair, you can run it once. If it says it could not repair the PC, stop and contact Desktop Support. Do not reset the PC.
      • BitLocker: A recovery prompt after a hardware change or several failed starts is normal. Do not turn BitLocker off. If you are stuck at the prompt, follow the BitLocker recovery key steps.
      • BitLocker recovery key: Your key is in the ACME device record, not in personal email. Contact the service desk, give them your PC name, and they can read the key to you or send it only to your company email.
      • Windows activation: Connect to the corporate network or VPN, then restart. If the activation watermark is still there, contact Desktop Support. Do not type in a product key you found online.
      • Temporary profile: Windows did not load your normal desktop and files. Restart and sign in once. If you see the temporary-profile message again, contact Desktop Support. Do not save work in that session, because Windows discards it when you sign out.
      • Windows Search: Restart the PC, then search again from the taskbar. If files you know are there still do not appear, contact Desktop Support. Do not rebuild the search index yourself.
      • Microsoft Store: Open the Microsoft Store, go to Library, and choose Get updates. If an app still will not install, note the error and contact Desktop Support. ACME does not support personal Store purchases.
      • Windows Hello: Try your password once. If the password works and face, fingerprint, or PIN does not, open Settings, remove that sign-in method, and add it again. If the password also fails, follow Password Reset.
      • Lock screen: If you see the lock screen but cannot sign in, follow Password Reset. If the screen is frozen before the lock screen, hold the power button and restart once.
      • Will not wake from sleep: Press a key, then press the power button once. If the screen stays black, hold the power button for 10 seconds and start the PC normally. If this keeps happening, contact Desktop Support and mention any dock or external monitor.
      • Windows will not shut down: Close your apps and use Start, Power, Shut down. If it stays on Shutting down for more than 10 minutes, hold the power button for 10 seconds. If this happens every day, contact Desktop Support and say which app was open.
      • Display settings: If an external screen is blank, check the cable and press Windows+P, then choose Extend or Duplicate. Change resolution in Settings, System, Display. If the built-in screen is black and an external screen works, contact Desktop Support.
      • Device Manager: Open Device Manager and look only for a yellow mark next to a device. Do not remove a device. Write down the device name and contact Desktop Support.
  • Printer
    • Topic Matchings
      • Ink Cartridge, Anything related to a printer, Paper jam, Printer offline, Printer will not print, Print queue, Stuck print job, Printer driver, Toner, Out of paper, Printer not found, Network printer, Wireless printer, Default printer, Blank pages, Faded print, Cannot scan, Label printer
    • Troubleshooting Guidance
      • Ink Cartridge: Check the printer model and which color the message names. Open the cover and reseat that cartridge. If it still says empty or unrecognized, request a replacement through the ACME supply process. Do not try a chip reset.
      • Anything related to a printer: If your printer problem does not match a more specific item below, note the printer name, where it sits, and exactly what it is doing, then contact field support.
      • Paper jam: Turn the printer off, open the trays and the rear door, and pull the paper out in the direction it normally travels. Close the doors and turn the printer on. If the jam message stays, contact field support.
      • Printer offline: Confirm the printer is on. On your PC, open the printer queue and turn off Use Printer Offline. If it stays offline, note the printer name and contact field support.
      • Printer will not print: Print a one-page test. If the job stays in the queue, follow the print-queue steps. If the job disappears and nothing prints, check paper and toner, then contact field support.
      • Print queue: Open the queue and cancel the stuck documents. You can restart the Print Spooler on your own PC. Do not restart a spooler on a shared print server. If a server queue stays stuck, contact field support.
      • Stuck print job: Cancel that job, then print it once more. If the same document sticks again, note the app and the printer name and contact field support.
      • Printer driver: Do not remove the printer driver yourself. Confirm the ACME printer package is installed. If the driver shows an error, contact Desktop Support and tell them the printer model.
      • Toner: Note which color the printer names. You can keep printing while it says low. When it says replace, request a cartridge. Do not shake a cartridge over your desk.
      • Out of paper: Load the tray named on the printer display, and match the paper size to the job. If it still asks for paper, check that the guides in the tray are snug against the paper.
      • Printer not found: Connect to the corporate network or VPN, then search for the printer by its ACME name. If it still does not appear, contact support and tell them the building and floor.
      • Network printer: Use the name printed on the printer label. If other people on your floor can print, the problem is your PC. If nobody can print, contact support and report a printer outage.
      • Wireless printer: Confirm the printer is on the ACME wireless network, not a guest network. If it dropped off, reconnect it with the setup sheet. If this is your own home printer, ACME supports it only when you are a remote worker using that printer.
      • Default printer: Turn off Let Windows manage my default printer, choose the ACME printer you need, and print one test page.
      • Blank pages: Check that the job is not set to print only a separator page. Check toner and the paper type. If pages come out blank, contact field support.
      • Faded print: Notice whether one color is faint or every color is faint, then print the supply status page. If a color is low, follow the toner steps. If the supplies are fine, contact field support.
      • Cannot scan: Scan to your own email or to a folder you can open. Try one scan from the printer panel. If it never arrives, note the printer name and the time, then contact support.
      • Label printer: Set the label size in the app to the same size as the roll in the printer, then calibrate once from the printer menu. If labels skip or print off the edge, contact support and give them the model.

  • Password Reset
    • Topic Matchings
      • Forgot my Password, Password not working, Cannot log in, Account locked, Password expired, Reset password, Temporary password, Cannot change password, New password rejected, Multi-factor authentication, MFA code, Authenticator app, SMS code, Account disabled, Username not recognized, Single sign-on, SSO, Windows password, Email password, Domain password, Self-service password reset, Security questions, PIN not accepted
    • Troubleshooting Guidance
      • Forgot my Password: Go to the ACME password portal and complete the identity check there. Set a new password on your own screen. Do not tell anyone your old password or the new one you want to use.
      • Password not working: Check that Caps Lock is off and that you are using your company account. If it still fails, reset it in the ACME password portal. Do not give your password to anyone to type for you.
      • Cannot log in: Notice which sign-in fails: Windows, email, VPN, or one app. For Windows or email, use the password portal. If your password works and only one app fails, follow that app's steps.
      • Account locked: Wait 15 minutes and try again. If you still cannot get in, use the ACME password portal to unlock the account after the identity check. Do not ask someone else to unlock an account they cannot verify is yours.
      • Password expired: At the sign-in prompt, choose a new password that meets the ACME length rules and is not one of your recent passwords. The portal will not accept a password someone else picks for you.
      • Reset password: Open the ACME password portal, complete the identity check, and set the new password on your own screen. Do not send a password in email or chat.
      • Temporary password: A temporary password works once. Sign in with it, then change it immediately. The service desk will say it to you only after you pass the identity check. Do not ask them to text it to a personal number.
      • Cannot change password: Connect to the corporate network or VPN, then try again. If the portal says you used that password before, pick one that is not in your recent history. If the portal itself shows an error, contact the service desk.
      • New password rejected: Choose a password that meets the length rules and does not contain your name or account name. Do not use a password someone suggested to you.
      • Multi-factor authentication: Look at the prompt and see whether it is the app, a phone call, or a text. If you have that device, approve the prompt. If you do not have it anymore, contact the service desk and complete the identity check before you enroll a new device.
      • MFA code: Open the ACME authenticator, or use the company phone number registered on your account. Do not read a code to someone as proof of who you are. If codes keep failing, contact Identity.
      • Authenticator app: Open the ACME authenticator and confirm it shows your account. If the app was wiped, contact the service desk, pass the identity check, and then enroll it again. Do not use an authenticator link from an unexpected email.
      • SMS code: Codes go to the mobile number registered on your company account. If you have a new phone, contact the service desk and pass the identity check before you change that number.
      • Account disabled: A disabled account is not a temporary lock. You cannot turn it back on yourself. Ask your manager to approve access, or contact Identity.
      • Username not recognized: Try your full ACME email address, not a nickname. If the portal says there is no account, this is an access request, not a password reset. Contact the service desk.
      • Single sign-on: If one ACME app fails and your other ACME apps work, your password is fine. Follow that app's steps. If every ACME app fails, follow Password Reset.
      • SSO: If one ACME app fails and the others work, follow that app's steps. If every app fails, follow the password or MFA steps.
      • Windows password: This is the password on the PC sign-in screen. Reset it in the ACME password portal, then sign in. If you also see a BitLocker prompt, follow the BitLocker steps. Do not try to skip BitLocker.
      • Email password: ACME mail uses your company password. Reset that password, then update the password saved in Outlook. Do not create a separate mailbox password.
      • Domain password: Your domain password is your company password. Reset it in the portal, then lock and unlock Windows so the PC picks up the new password.
      • Self-service password reset: Open the ACME reset page and use your registered phone or authenticator. If reset is not set up yet, contact the service desk, pass the identity check, and enroll before you reset.
      • Security questions: ACME does not reset passwords with personal security questions. Use the password portal and your registered MFA method. Do not give a family name or similar answer as proof of identity.
      • PIN not accepted: If it is a Windows Hello PIN, follow the Windows Hello steps. If it is a badge PIN, follow Building Access. If it is a phone PIN, follow Mobile Device. Reset the PIN on the screen instead of saying it out loud.
  • Applications
    • Topic Matchings
      • Salesforce, Outlook, Microsoft Teams, Excel, Word, PowerPoint, OneNote, OneDrive, SharePoint, Microsoft 365, Adobe Acrobat, Webex App, Zoom, Slack, Google Chrome, Microsoft Edge, Google Drive, Gmail, Workday, SAP, ServiceNow, Jira, Confluence, DocuSign, Box, Okta, Power BI, Dynamics 365
    • Troubleshooting Guidance
      • Salesforce: Open the ACME Salesforce address in Chrome or Edge. If sign-in fails, follow Password Reset. If a record will not save, note the error and contact the Salesforce admin queue.
      • Outlook: Close Outlook and open it again. If mail will not send or arrive, follow the Email steps. If Outlook will not open, start it in safe mode once. If it still fails, contact Desktop Support and include the error.
      • Microsoft Teams: Sign out of Teams and sign back in. If chats will not load, connect to VPN or the corporate network. For meeting audio or video, follow the Meetings steps.
      • Excel: Close the file and open it again. If Excel says the file is locked, ask the person named on the screen to close it. If Excel closes on only that file, make a copy and open the copy. Do not run an Office repair yourself.
      • Word: Close the document and open it again. If Word offers a recovered copy, save it with a new name. If Word closes on every document, contact Desktop Support.
      • PowerPoint: Close the deck and open it again. If one slide makes PowerPoint close, note that slide number and contact Desktop Support.
      • OneNote: Open your ACME notebook, not an old copy stored only on the PC. If sync fails, connect to the network and try again. Do not delete the notebook. If the error remains, contact support and include the error text.
      • OneDrive: Select the cloud icon and confirm you are signed in with your ACME account. Files that say online only can take a minute after you connect to VPN. Do not unlink OneDrive.
      • SharePoint: Open the site in Edge or Chrome. If you see access denied, ask the site owner for access. This is not a password reset. Copy the site address into your request.
      • Microsoft 365: Use this when several Office apps fail at the same time. Sign out of Office and sign in with your ACME email. If activation still fails, contact Desktop Support.
      • Adobe Acrobat: Open the PDF in Acrobat instead of only in a browser tab. If one file fails, ask the sender for a new copy. If every PDF makes Acrobat close, contact Desktop Support.
      • Webex App: Sign out of the Webex app and sign back in. For calls and meetings, follow the Meetings steps. If the app will not open, note the error and contact support.
      • Zoom: Join from the invitation you were sent. Do not install Zoom from a link in an unexpected email. For audio or video, follow the Meetings steps.
      • Slack: Confirm you are in the ACME workspace, then sign out and back in. If a channel is missing, ask a workspace admin and include the channel name.
      • Google Chrome: Try the same page in Edge. If only Chrome fails, close Chrome and open it again. Do not clear your saved passwords or all browsing data.
      • Microsoft Edge: Try the same page in Chrome. If only Edge fails, close Edge and open it again. If both browsers fail, check your network or VPN.
      • Google Drive: ACME does not use personal Google Drive for company files. You can open a partner's Drive link in Chrome. Do not move ACME files into a personal Drive.
      • Gmail: ACME mail is Outlook, not personal Gmail. Do not reset a personal Gmail password through this service desk.
      • Workday: Open Workday from the ACME portal. For a page error, note the time and contact the Workday admin queue. Do not change your own pay or job data from an error screen.
      • SAP: Open SAP from the ACME portal. Write down the transaction code and the exact error, then contact support. Do not post or reverse a transaction to test it.
      • ServiceNow: Open the ACME ServiceNow address and confirm you are signed in as yourself. If your ticket is missing, include the incident number when you contact support. If the whole site is down, contact the service desk.
      • Jira: Open the ACME Jira site. If a project is missing, ask that project's admin and include the project key. Include any error text.
      • Confluence: Open the page address you were given. If you see access denied, ask the space owner. If the page fails for everyone, contact the Confluence admin queue.
      • DocuSign: Open the envelope from the message in your ACME email, not from a forwarded copy. Do not share a signing code with anyone.
      • Box: Open Box from the ACME portal. If you see access denied, ask the folder owner. Do not download a folder to a personal computer unless that file is approved for it.
      • Okta: If Okta itself will not sign you in, follow Password Reset or the MFA steps. If Okta opens and only one app tile fails, follow that app's steps.
      • Power BI: Open the report from the ACME Power BI link. If the report is blank, note the report name and contact support. Do not change a dataset.
      • Dynamics 365: Open Dynamics from the ACME portal. If you see access denied, ask the Dynamics owner. Note the module and the error. Do not edit customer records to test access.
  • Remote Access
    • Topic Matchings
      • VPN, virtual private network, MRA, mobile remote access, VDI or virtual desktop, Cisco AnyConnect, VPN will not connect, VPN disconnects, VPN is slow, Cannot reach internal sites, Remote desktop, Citrix, VMware Horizon, Virtual desktop will not launch, Home network, Proxy, Zscaler, Split tunnel, RDP, Secure access client
    • Troubleshooting Guidance
      • VPN: Use the ACME VPN client, not a personal VPN, and disconnect any other VPN first. If the ACME client is not installed, contact Desktop Support.
      • virtual private network: Follow the VPN steps. Use the ACME client. If it fails, write down the error text and contact Desktop Support.
      • MRA: Mobile and Remote Access lets a Webex phone register when you are off the corporate network. If the phone will not register, disconnect VPN and try again. Note the device and the error, then contact Collaboration Support.
      • mobile remote access: Follow the MRA steps. Note your device, the error, and whether VPN is also connected, then contact Collaboration Support if it still fails.
      • VDI or virtual desktop: Notice whether the desktop never opens or opens and then closes. Restart the virtual-desktop client once. If it still fails, note the desktop pool name and contact the virtual-desktop queue.
      • Cisco AnyConnect: Open AnyConnect, choose the ACME gateway, and connect. If the password is rejected, follow Password Reset. For any other error, write it down and contact Desktop Support.
      • VPN will not connect: First open a public website. If that opens, try AnyConnect once. If the public site works and VPN does not, write down the error and contact Desktop Support. Do not change your home router settings.
      • VPN disconnects: If it drops when the PC sleeps, wake the PC and connect again. If it drops when you change Wi-Fi, reconnect after the new network is up. If it drops at random, note the time and whether you are on Wi-Fi or a cable, then contact Desktop Support.
      • VPN is slow: If only one app is slow, follow that app's steps. If file shares and every internal site are slow, contact Desktop Support.
      • Cannot reach internal sites: Confirm the VPN client says connected, then open the ACME intranet. If VPN is connected and the intranet still fails, note the site address and contact Desktop Support.
      • Remote desktop: Connect with the PC name, not an old address, and confirm that PC is turned on. If it is off, someone at that desk needs to turn it on, or support can try a remote wake. Do not ask for a local admin password.
      • Citrix: Open the ACME Citrix site and launch the desktop or app once. If it fails, write down the error and contact the virtual-desktop queue.
      • VMware Horizon: Open the ACME Horizon client and connect to the server named in your instructions. If the desktop stays on loading, close the client and open it once. If it fails again, note the pool name and contact the virtual-desktop queue.
      • Virtual desktop will not launch: Note whether you use Citrix or Horizon, then restart that client once. If the desktop stays black, contact the virtual-desktop queue. Do not reinstall the client yourself.
      • Home network: Open a public website. If it opens, your home internet is up and you should follow the VPN steps. If no public site opens, contact your internet provider. ACME cannot repair a home internet outage.
      • Proxy: Do not change proxy settings yourself. If the browser says it cannot find the proxy, connect to VPN and restart the browser. If the ACME proxy setting is missing, contact Desktop Support.
      • Zscaler: Open the Zscaler client and confirm it shows your ACME user. If you are signed in and a site still fails, note the site and contact support. Do not turn Zscaler off.
      • Split tunnel: You cannot turn split tunnel on or off. If a public site works and an internal site does not, note that internal address and contact Desktop Support.
      • RDP: Follow the Remote desktop steps. Use the PC name, make sure that PC is on, and do not share a local admin password.
      • Secure access client: Open the ACME secure access client and connect. If sign-in fails, follow Password Reset. For any other message, write it down and contact Network Support.
  • Email
    • Topic Matchings
      • Spam, Phishing, or Fishing, Bad attachment, Not receiving emails, Cannot send email, Mailbox full, Out of office, Shared mailbox, Distribution list, Quarantine, Junk folder, Suspicious email, Spoofed email, Undeliverable, Bounce back, Attachment too large, Encrypted email, Missing email, Delayed email, Email forwarding, Outlook on the web, Exchange, Email rules, Calendar invite
    • Troubleshooting Guidance
      • Spam: In Outlook, use Report or move the message to Junk. Do not click links or open attachments. If several people got the same message, note the subject and sender and contact Security.
      • Phishing, or Fishing: Do not click, reply, or forward the message. Use the ACME report-phishing button. Note the sender and subject, then contact Security.
      • Bad attachment: Do not open the attachment. If you already opened it, do not forward the message. Note the file name and contact Security.
      • Not receiving emails: Check Junk and quarantine, and note who sent the message and when. Send a test message to yourself. If your test does not arrive, contact Email Support.
      • Cannot send email: Read any bounce message. Send a test to your own ACME address. If it stays in Outbox, restart Outlook once. If it is still stuck, contact Email Support.
      • Mailbox full: Delete or archive mail until you are under the limit. Start with Deleted Items and messages that have large attachments. The quota is not raised during a support call.
      • Out of office: In Outlook, open File, Automatic Replies, turn replies on or off, and set the dates. Write the reply text yourself.
      • Shared mailbox: If you were given access, close Outlook and open it again so the mailbox appears. If you were never given access, ask the mailbox owner. There is no separate password to collect.
      • Distribution list: Note the list name and whether you need to send to it or join it. Ask the list owner to change membership.
      • Quarantine: Open the ACME quarantine notice and release only mail you recognize. If you have no notice, check Junk. If the message looks suspicious, contact Security before you release it.
      • Junk folder: Look in Junk for the missing message. You can mark a known ACME sender as not junk. Do not mark an unexpected external sender as safe.
      • Suspicious email: Do not click anything in the message. Use the report button. Note the sender, the subject, and whether you opened a link, then contact Security.
      • Spoofed email: If the name looks like a coworker but the address does not, do not reply. Check the full address, use the report button, and contact Security.
      • Undeliverable: Read the bounce reason. If the address is wrong, correct it and send again. If the bounce mentions a policy or a blocked attachment, contact Email Support. Do not keep resending a rejected message.
      • Bounce back: Follow the undeliverable steps. Note the status code and the recipient. If only one person in a large message bounced, remove that address and send again to the others.
      • Attachment too large: Put the file in OneDrive or SharePoint and send a link. Do not try the same oversized attachment again.
      • Encrypted email: Open it in Outlook while you are signed in with your ACME account. If it sends a one-time passcode, that code belongs only in your ACME mailbox. Do not forward the message to a personal account.
      • Missing email: Note the sender, subject, and about when it was sent. Check Junk and quarantine. If it is not there, contact Email Support with those details.
      • Delayed email: A delay of a few minutes can be normal. If mail is hours late for you and for other people, contact Email Support and tell them the time it was sent.
      • Email forwarding: Turn off forwarding to a personal mailbox. That is not allowed. If you need mail to go to another ACME mailbox, ask that mailbox owner.
      • Outlook on the web: Open ACME Outlook on the web in Edge or Chrome. If the website works and the Outlook app does not, the problem is the app. If both fail, check your password and whether mail is up.
      • Exchange: If both the Outlook app and Outlook on the web fail for you and for other people, contact Email Support and tell them the time it started. Do not rebuild your mail profile during an outage.
      • Email rules: In Outlook, open Rules and turn off the newest rule if messages are disappearing. Do not delete every rule. Turn off any rule that forwards mail outside ACME.
      • Calendar invite: Look for the invite in your mailbox, including Junk. Accept it in Outlook. If you still cannot join after you accept, follow the Meetings steps.
  • Building Access
    • Topic Matchings
      • Badge is damaged, damaged badge, Card reader not working, Can’t get into building, Physical access, Badge not working, Lost badge, Forgot badge, Visitor badge, Temporary badge, New badge request, Badge expired, Door will not unlock, After-hours access, Turnstile, Elevator access, Parking garage access, Floor access, Lobby, Tailgating report
    • Troubleshooting Guidance
      • Badge is damaged: If the badge is cracked or bent, take it to the lobby or the badge office with your photo ID and get a replacement. A taped badge will not read reliably.
      • damaged badge: Take the badge to the lobby or the badge office with your photo ID for a replacement. Do not keep tapping a broken card.
      • Card reader not working: Watch whether other people can use that same door. If nobody can, contact Security and report the door. If only your badge fails, follow the badge-not-working steps.
      • Can't get into building: Note the door and the time. After hours, that door may be locked to your access. If your badge should work, contact Security. Stay where you are if you are locked outside.
      • Physical access: If this is a door, badge, or entry problem and none of the other items fit, note the building, the door, and the time, then contact Security. Do not follow someone else through the door.
      • Badge not working: Try a different reader. If that reader works, the first reader is the problem and you should tell Security which door failed. If no reader works, contact Security about your badge.
      • Lost badge: Do not borrow someone else's badge. Contact Security so they can disable the lost badge. Go to the badge office with photo ID for a replacement the same day.
      • Forgot badge: Go to the lobby with photo ID and ask for a temporary badge. Do not ask a coworker to badge you through.
      • Visitor badge: Sign in at the lobby. Your host has to be notified. A visitor badge is issued only through that desk.
      • Temporary badge: Temporary badges expire. If yours expired and your visit or forgotten-badge reason is still valid, the lobby can replace it. Check the date on the badge.
      • New badge request: Ask your manager to submit a badge request to the badge office. Include your start date and site. A badge is not created over the phone.
      • Badge expired: Take photo ID to the badge office. Access is not extended over the phone. If you are locked out now, lobby security can issue a temporary badge after they check your identity.
      • Door will not unlock: Notice whether the reader beeps or lights. If it is dead for everyone, contact Security. If it denies only your badge, contact Security to check your access.
      • After-hours access: After-hours doors follow the building schedule. If your role should have access and the door still denies you, note the door and the time and contact Security. You cannot override the schedule yourself.
      • Turnstile: Badge once and wait for the green light. A red light means access was denied. If the turnstile does not move for anyone, contact Security.
      • Elevator access: Note the elevator and the floor you need. Ask your manager to request the floor change from Security. Do not use another path around a locked floor.
      • Parking garage access: Try your badge once at the gate. If it should open and does not, contact Security and name the gate. Do not follow another car through.
      • Floor access: If you can enter the building but not your floor, ask your manager to request that floor from Security. Do not ask a coworker to hold the door.
      • Lobby: Employees use the lobby badge reader. Visitors use the visitor desk. If the lobby reader is down, contact Security and use the site check-in process.
      • Tailgating report: Note the door, the time, and what you saw, then contact Security the same day. Do not confront the person.
  • Emergency
    • Topic Matchings
      • Any type of emergency or danger, Employee health issues, Workplace violence
    • Troubleshooting Guidance
      • Any type of emergency or danger: If you or someone else is in immediate danger, contact local emergency services first, then site Security. Stay on the phone only if you are in a safe place. Do not go look for the problem.
      • Employee health issues: If someone needs urgent medical help, contact local emergency services and site Security. Do not try to treat them from these steps. For a non-urgent benefits question, use the HR service desk.
      • Workplace violence: Go to a safe place, then contact local emergency services and site Security. Do not go toward the incident. Tell Security only what you already saw.
  • Meetings
    • Topic Matchings
      • Webex Meetings, Webex, Teams Meetings, Zoom Meetings, Google Meet, Cannot join meeting, Meeting link, No audio in meeting, No video in meeting, Screen share, People cannot hear me, Echo on the call, Waiting room, Meeting lobby, Dial-in number, Webex recording, Personal room, Host controls, Breakout room, Virtual background, Webinar, Meeting invite, Camera not detected in meeting
    • Troubleshooting Guidance
      • Webex Meetings: Join from the ACME Webex app or the link in the invite. If you are in the meeting and audio or video fails, follow those steps. If you cannot get in, note the meeting number and contact support.
      • Webex: If the Webex app will not open, follow the Webex App steps. If you are in a conference room, follow the Conference Room steps. If you are joining a meeting, stay with the meeting steps on this page.
      • Teams Meetings: Join from the meeting on your Teams calendar, not from an old link. If you have no audio, follow the no-audio steps. If Teams will not open, follow the Microsoft Teams steps.
      • Zoom Meetings: Join from the invitation you were sent. Do not install Zoom from a link that was not in that invite. For audio or video, follow those steps.
      • Google Meet: Open the Meet link in Chrome or Edge. If the browser blocks the camera, allow the camera for that site and try again.
      • Cannot join meeting: Note which app you are using and whether you see a password, a waiting room, or an error. For a password or a lobby, follow those steps. Otherwise copy the error, use the link from the latest invite, and try once more.
      • Meeting link: Use the link in the newest invite. An older link may be expired. If it opens the wrong meeting, ask the host for a new link. Do not forward the link to people who were not invited.
      • No audio in meeting: In the meeting, select your speaker and microphone. Disconnect a Bluetooth headset and try the PC speakers once. If people still cannot hear you, follow the People cannot hear me steps.
      • No video in meeting: In the meeting, select your camera and open any lens cover. Close other apps that use the camera. If your camera is not in the list, contact Desktop Support.
      • Screen share: Ask the host to allow sharing, then share a window or your screen from the meeting controls. If the share is a black window, stop sharing and start it again. Do not install another share tool.
      • People cannot hear me: Turn mute off and watch the microphone meter while you talk. If it does not move, switch from your headset to the PC microphone. If it still does not move, contact Desktop Support.
      • Echo on the call: Leave the meeting on every device except one. A PC and a phone in the same room cause echo. Use a headset, or turn the speaker down.
      • Waiting room: Wait there until the host admits you. If you have been waiting more than a few minutes, message the host. You cannot skip the waiting room.
      • Meeting lobby: Stay in the lobby until the host admits you. If the host says they cannot see you, send them the meeting name.
      • Dial-in number: Call the dial-in number in the invite and enter the access code from that same invite. Use your own phone. Do not post the code in a public chat.
      • Webex recording: If you are the host, open your Webex recordings after the meeting finishes processing. Do not download a recording to a personal device unless you are allowed to keep it.
      • Personal room: Use the host's personal-room link. If the room is locked, wait for the host to admit you. Do not email a personal-room PIN.
      • Host controls: Only the host can mute others, lock the meeting, or start a recording. If you are the host and the controls are missing, leave and rejoin while you are signed in with your ACME account.
      • Breakout room: Wait for the host to assign you. If you were not moved, ask the host to assign you. Only the host can create a breakout room.
      • Virtual background: In the meeting video settings, choose a background. If your video freezes, turn the background off. If you do not see the option, your device does not support it.
      • Webinar: As an attendee you usually stay muted and cannot share. If you are a panelist and cannot speak, ask the host to promote you. Have the webinar name ready.
      • Meeting invite: Look on your calendar, and also check Junk email. If the invite is not there, ask the organizer to resend it. After you accept it, use the Meetings steps if you still cannot join.
      • Camera not detected in meeting: Close other apps that use the camera, leave the meeting, and join again. If Windows also cannot see the camera, follow the Device Manager steps and contact Desktop Support.
  • Conference Room
    • Topic Matchings
      • Video, Room System, Cisco Room Kit, Room Bar, Room Bar Pro, Board, Board Pro, HDMI sharing cable, USBC sharing, Wireless sharing (Miracast, Apple sharing, Airplay), Room offline, Room will not join, No display in room, Touch panel, Navigator, Room camera, Room microphone, Room speaker, Room volume, One-touch join, Room calendar, Content will not share, Cable missing, USB-C adapter, Room booking, Codec offline, Webex Room
    • Troubleshooting Guidance
      • Video: If this is your laptop camera, follow the Meetings camera steps. If this is the camera or display in a conference room, note the room name on the door and stay with the room steps below.
      • Room System: Read the room name on the door or on the touch panel, then choose one-touch join. If the panel is dark, follow the room-offline steps.
      • Cisco Room Kit: If the touch panel says offline, contact Collaboration Support and give them the room name. Do not unplug the codec unless they ask you to.
      • Room Bar: Note the room name and try one-touch join. If the display has no picture, check that the HDMI cable is seated, then contact Collaboration Support.
      • Room Bar Pro: Note the room name and what the touch panel shows. Do not restart the bar unless support asks. If it says offline or the camera is black, contact Collaboration Support.
      • Board: If the Board is on but will not join the meeting, try once from the touch panel. If the Board is black, check that it has power, then contact Collaboration Support with the room name. Do not factory reset it.
      • Board Pro: Follow the Board steps. Note the room name and whether the panel responds when you touch it.
      • HDMI sharing cable: Plug the room HDMI cable into your laptop. If the laptop does not see the display, press Windows+P and choose Duplicate or Extend. If the cable is gone, follow the cable-missing steps.
      • USBC sharing: Plug in the room USB-C cable and accept the display prompt on your laptop. If the plug does not fit, follow the USB-C adapter steps.
      • Wireless sharing (Miracast, Apple sharing, Airplay): Follow the wireless instructions on the room panel. Use Miracast on Windows and AirPlay on Apple. If the room name does not appear, use the cable instead. Do not join a guest network just to share.
      • Room offline: Read the room name. If the touch panel is dark or says offline, contact Collaboration Support. Do not move your meeting into a room someone else has booked.
      • Room will not join: Check that the meeting is on the room calendar, then press one-touch join once. If the room dials and fails, note the meeting number and contact Collaboration Support.
      • No display in room: Turn the display on and select the input that matches the cable you are using. If the input is correct and the picture is still black, contact Collaboration Support with the room name.
      • Touch panel: If the panel is frozen, contact Collaboration Support. Do not pull it off the wall. If it responds but the meeting buttons are missing, tell them the room name. The room may not be registered.
      • Navigator: If the Navigator does not list your meeting, check that the room is on the meeting invite. If the Navigator is offline, contact Collaboration Support with the room name.
      • Room camera: If the other side cannot see the room, make sure the camera is uncovered and pointed at the table. If a test call still shows a black picture, contact Collaboration Support. Do not try to refocus a fixed camera by hand.
      • Room microphone: If the other side cannot hear the room, turn mute off on the touch panel and have one person speak. If they still hear nothing, contact Collaboration Support.
      • Room speaker: If you cannot hear the other side, raise the volume on the touch panel once. If there is still no sound, contact Collaboration Support. Do not plug your own speaker into the room equipment.
      • Room volume: When the sound is coming from the room, use the volume buttons on the touch panel and set them near the middle. If the level does not change, contact Collaboration Support.
      • One-touch join: The join button appears when the meeting includes this room and it is time to start. If you do not see it, check the room booking and the start time.
      • Room calendar: Add the room itself to the meeting, not only the people. Wait a minute, then look at the panel again.
      • Content will not share: Try the HDMI or USB-C cable once. If a different laptop can share, the problem is your laptop. If no laptop can share, contact Collaboration Support.
      • Cable missing: Note whether the HDMI cable or the USB-C cable is missing. Use wireless sharing if the panel shows it, and tell workplace services which cable is gone.
      • USB-C adapter: If your laptop has only HDMI, use the HDMI cable. If the USB-C plug does not fit, note your laptop model and contact support. Do not force the connector.
      • Room booking: Book the room on the ACME calendar and include the room on the meeting. If the panel says the room is busy but the room is empty, note the time and contact the person who booked it.
      • Codec offline: Contact Collaboration Support and give them the room name. Do not restart equipment in a rack unless they ask you to.
      • Webex Room: If none of the room items above match, note the room name, what the touch panel shows, and whether you also have a laptop connected, then contact Collaboration Support.
